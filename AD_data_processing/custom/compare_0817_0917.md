## 3. 0817에 남은 문제

### 3.1 실행이 바로 막히는 것

- **`custom/env_server.sh`가 없다.** `run_preprocess_adni.sh:15`가 `source custom/env_server.sh`를 하고 `set -e`라서 시작하자마자 종료한다. `pipeline.require_tools()` 에러 메시지도 이 파일을 가리킨다 (`pipeline.py:43`). git에도 untracked에도 없음 → 만들거나 경로를 고쳐야 한다.
- `make_adni_csv.py`를 단독 실행하면 `--exclude_csv` 기본값이 지워진 `custom/adni_qc_failed.csv`라서 `FileNotFoundError` (`make_adni_csv.py:433`). `run_adni.sh`는 `QC_FAILED=""`를 넘겨서 괜찮다.

### 3.2 결과에 영향을 주는 것

- **diagnosis 결측 = -1 + `PAIR_DX_MISSING=keep`(기본).** -1이 그대로 pair에 남으면 dia diff가 다시 무의미한 값이 된다 (예: 결측→AD = +2, CN→결측 = -1). old.md의 핵심 문제가 결측 행에서 재발하는 셈이다. `dx_window_days=0`(제한 없음)이라 결측은 DXSUM에 행이 아예 없는 피험자에서만 생기니 개수는 적을 것 — 리포트 `[4]`의 unmatched 수를 보고 0이 아니면 `PAIR_DX_MISSING=drop`을 권장.
- **antsRegistration 시드 미설정 (old.md #7).** `MI[...,Regular,0.1]`의 Regular 샘플링도 랜덤 perturbation을 쓰므로 재실행 시 affine이 미세하게 달라진다. `--random-seed <int>`를 추가하면 재현 가능 (ITK 멀티스레드 때문에 완전 bitwise 동일은 보장 안 됨).
- **split 미반영 (#9).** 리포트 `[5]`가 split 파일 vs md5 hash 교차표를 보여준다. 로더를 패치하지 않으면 학습은 hash split으로 돌고, `vol_norm_ref=train`의 "train"과 실제 학습 train이 달라서 #2 수정 효과가 일부 깨진다.

### 3.3 사소한 것

- `--pair_dx_missing` help에 "drop (default)"라고 써있지만 실제 default는 `keep` (`make_adni_csv.py:451-452`).
- `pipeline.resample`은 `scipy.ndimage.zoom` 후 affine의 translation을 그대로 둔다 → 원점이 반 voxel 정도 어긋남. seg/final 둘 다 똑같이 적용되므로 둘 사이 정합은 유지되고, upstream도 같은 방식.
- OASIS 경로(s1/s2)는 0817에서도 #1~#3이 그대로다. OASIS를 다시 쓸 일이 있으면 같은 수정이 필요하다.
